# 浮沉—推进 气压耦合实验：假设与验证方案

> 目的：验证"推进系统与浮沉 PID 同时工作时，是否会因共用外腔的气压耦合导致浮沉控制失效甚至倒灌"。

## 1. 系统背景

- 推进与浮沉**共用同一个外腔**（这是耦合的物理根源）。
- 两套气泵规格悬殊：

  | | 推进泵 Kamoer KVP8-KK（12V 并联）| 浮沉泵 DFRobot FIT0801（5V）|
  |---|---|---|
  | 正压 | ≥0.1 MPa（≈100 kPa）| 未标（量级 ~58 kPa）|
  | 真空 | −0.06 MPa | −58 kPa |
  | 流量 | 480 L/H（8 L/min）| 2.2 L/min |
  | 功率 | 8 W | 2.5 W |

- 浮沉由 PID 控制，但 PID 的**唯一执行手段**是：依据深度传感器，调节电磁阀的**开关时间**。
  它**既不直接测量腔内气压，也不直接计量气体流量**。

## 2. 核心假设（一句话）

> 推进与浮沉**同时工作**时，推进泵在共用外腔制造的周期性高压，会在浮沉泵膜片的工作间隙突破其单向密封，使气体**倒流进浮沉气囊**；同时 PID 因"只能控阀门时间、感知不到真实气压/气量"而**失去对实际进出气量的控制**，最终导致浮沉控制失效，严重时整个运动控制崩溃。

## 3. 机理链条（拆成可检验的环节）

**环节 A — 共用腔体把推进高压周期性灌向浮沉口**
推进泵往复工作，外腔气压周期性大幅波动（峰值可达 ~0.1 MPa）。因外腔与浮沉气路共用，这股高压周期性作用在浮沉泵/阀的接口上。

**环节 B — 浮沉泵膜片在间隙挡不住**
浮沉泵是小功率膜片泵（耐压量级仅 ~58 kPa）。在它**不主动泵气的间隙**，仅靠膜片/单向阀密封，**耐不住推进侧 ~100 kPa 的反压** → 气体倒流（倒灌）进气囊。

**环节 C — PID 的"感知—执行"双重盲区**
- 感知盲区：只有深度反馈，**测不到腔内真实气压**；
- 执行盲区：只能控**阀门开关时间**，而**开阀时间 ≠ 实际进/出气体体积**——同一段开阀时间内的气体量取决于当时瞬时压差，而压差正被推进周期性扰动。

**环节 D — 时间一致 ≠ 气量一致 → 控制错位**
于是出现矛盾结果：即便 PID 给出"应有"的阀门时序，实际压进/放出气囊的气体体积可能**与期望严重不符**（时多、时少、甚至方向相反）。浮沉控制与系统期望脱节。

**环节 E — 失效与最坏情况**
- 轻则：浮沉响应紊乱、控不准深度；
- 重则：推进气体**持续单向倒灌、越积越多压进气囊**，浮沉彻底失能，并可能反过来干扰整体运动控制。

## 4. 预期现象（实验中重点观察）

- 推进运行时，浮沉气囊（针筒）活塞被异常推动/充气，即使 PID 没要求；
- 相同的 PID 阀门时序下，浮沉表现**不可复现**（时多时少）；
- 深度无法稳定保持，或出现单向漂移；
- 档位越高（PID 越激进），紊乱/倒灌越明显。

## 5. 验证方案

- 桌面水缸放入机器人部件，**启动即让推进系统与浮沉 PID 同时工作**。
- PID 控制范围分 **3 档**，串口输入 **1 / 2 / 3** 切换，对比不同强度下的耦合程度。
- 串口实时输出：深度、目标、控制量、浮沉方向/PWM、推进状态，便于复盘。

## 6. 判据

- **假设成立**：同时工作时观察到倒灌 / 气囊异常充压 / 浮沉失准失效，且随档位加剧；
- **假设不成立**：两系统同时工作时浮沉仍能按期望进退、深度可控、无异常倒灌。

## 8. 结论（已定位）

问题**不在气囊蓄气，而在浮沉泵本身**：

1. 气囊(针筒)因活塞摩擦紧、无明显进出气位移 → 佐证气体**未蓄入气囊**，而是经浮沉泵泄到外面，外腔失气。
2. 浮沉泵(FIT0801)是膜片式单向阀泵，**膜片切换/打开的瞬间**存在短暂未密封窗口。
3. 该瞬间外腔(推进泵 KVP8 ≈0.1 MPa)气压**高于**浮沉泵输出气压 → 气体**短暂逆流**。
4. 叠加该型号泵**本身密封性不合格** → 表现为"全漏"。

**修复方向：**
- 首选：更换**密封合格、反向耐压 ≥ 推进满压(≥0.12 MPa)** 的浮沉泵；
- 加固：在外腔↔浮沉一侧串一道**优质止回阀**挡反压；
- 根治：按学长方案加**独立浮力腔**，让推进/浮沉不共腔，从结构上消除耦合。
